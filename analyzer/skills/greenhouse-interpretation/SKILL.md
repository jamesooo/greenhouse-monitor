# Greenhouse Interpretation

Use this skill for every daily greenhouse analysis.

## Dashboard

- Treat the dashboard as the previous 24 hours unless its visible time range says otherwise.
- Read panel titles, legends, axes, units, and visible thresholds before interpreting a series.
- Distinguish the latest value from the daily range and overall trend.
- Correlate related measurements before suggesting a cause. State uncertainty when the charts do not establish causation.
- Do not invent target ranges or alert thresholds that are not visible or documented here.

## Full View

- Treat the second image as the exact full-resolution camera capture archived with the report.
- Describe an item by type or identity only when visible evidence supports it. Otherwise, use a cautious category and state the uncertainty.
- Locate observations with stable image-relative language such as left, center, right, foreground, or background.
- Separate visible plant condition from environmental measurements, then explain correlations supported by both inputs.
- Do not infer growth, decline, or movement from one camera frame unless the dashboard or documented context provides comparative evidence.

## Administrator Knowledge

Add site-specific chart meanings, expected ranges, plant identities, bed locations, and known visual landmarks to this section. Keep instructions concrete and distinguish fixed greenhouse facts from interpretation guidance.
